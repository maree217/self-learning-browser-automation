## Challenges & Learnings

### LinkedIn DOM Structure Variability
- Different selectors between standard and Beta search
- Required adaptive extraction scripts
- Solution: Multi-selector fallback approach

### Token Limits on Full Page Content
- Initial attempts hit 248K token responses
- Solution: Targeted JavaScript extraction of job description only (3000 char limit)

### Browser Session Management
- Context closing errors between navigations
- Solution: Consistent domain usage (linkedin.com vs www.linkedin.com)

### Salary Data Scarcity
- Only 6% of jobs (2/32) listed salaries
- Makes comparison difficult
- Mitigated with company research and industry benchmarks
